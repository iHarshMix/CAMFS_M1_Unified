# Prompt Template

Paste one of these into the chat after uploading your content.

---

## Standard trigger

```
Break this down into visual stepper widgets.
Running example: [Client X, Sample Y, modalities {A, B, C} present, D missing]
Start with Widget 1 and wait for "continue".
```

---

## If you want Claude to pick the example

```
Break this down into visual stepper widgets.
Pick a concrete running example and use it throughout all widgets.
Start with Widget 1 and wait for "continue".
```

---

## To continue to next widget

```
continue
```

That's it. Claude reads the instructions.md from the project and knows exactly what to do.
